# Сравнение по характеристикам

Для каждой позиции общая панель собирает обнаруженные значения всех сохранённых предложений поставщиков. Совпадения с заявкой разрешены по умолчанию; ✓ разрешает альтернативу, ✕ исключает любое значение, включая совпадение. Разные параметры соединяются И, значения параметра — ИЛИ. Неразобранные слова остаются отдельными проверками соответствия; разрешение одного слова не разрешает другие отличия. Неизвестные и неоднозначные сведения требуют явного разрешения и привязаны к версии предложения.

После сохранения значения сервер автоматически пересчитывает все варианты всех поставщиков и минимум за единицу заявки. Упаковки переводятся по известному количеству; цена за штуку повторно на упаковку не делится. Неизвестный коэффициент, неположительная цена, неизвестные финансовые условия, выключенное предложение/поставщик и исключённая позиция не участвуют в минимуме. Наличие и недопоставка отображаются отдельно; сравнение цены не подтверждает возможность полной поставки. Доставка в минимум не входит.

Принятое временное правило актуальности: 30 календарных дней. Будущие даты, старые цены и цены без даты показаны в деталях с причиной исключения. Для новых ответов API сохраняется время получения цены; открытие страницы его не обновляет. Финансовые условия с известными значениями не требуют отдельного подтверждения цены.

Решения сохраняются по позиции и исходной заявке (наименование, количество, единица), независимо от сортировки предложений. Изменённая заявка не наследует решения. Сравнение не меняет выбор закупки, количество или отправленный счёт. Повторная обработка и отправка счёта остаются отдельными действиями.

Проверка: логические и HTTP тесты в test_characteristic_comparison.py и test_supplier_comparison.py; прежние сценарии каталога, матрицы и адаптера КРЕП-КОМП. В браузере проверены начальный минимум, добавление альтернативы, исключение исходного совпадения и перезагрузка.
