# Стенд подбора товаров

Сохранённые версии стенда логики подбора «Закупай MVP». Эта ветка не публикуется на Render.

- В1 (08.11.2026): podbor-v1.html — рубрики характеристик, кнопки ✓/+/✕, справочник, таблица с группами «Данные заявки / Данные поставщика».

- В2 (09.11.2026): podbor-v2.html — сводка заявки, одно упорядочивание товаров (подходящие / близкие / остальные), эталон «Взять за основу», быстрые нажатия, ИИ-подбор и вопросы. Описание правил: SPEC-v2.md.

- В3 (13.11.2026): podbor-v3-groups.html — экран подбора из приложения (тот же файл, что comparison_assets/podbor.html) с группами: товары с одним набором характеристик (без артикула, бренда, фасовки) — одна строка с самым дешёвым предложением, остальные свёрнуты под ней; внутри «Подходящие» два уровня — «подтверждены все значения заявки» и «не всё указано в названии». Данные — реальный прайс Сатурна от 12.11.2026; три строки «условный пример» добавлены только для показа группы из нескольких поставщиков, их цены выдуманы.
