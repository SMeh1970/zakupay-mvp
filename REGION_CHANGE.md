# Регион заявки

Источник — `region.name` исходной заявки Закупай (также поддерживается строковый `region`). Город и адрес не используются для определения региона. Пустые значения отображаются как «не указан».

API возвращает исходные заявки без удаления поля `region`. Импорт сохраняет их в `automation_jobs.order_json` в SQLite/PostgreSQL; отдельный столбец и миграция схемы не требуются. `saved_dashboard.describe` читает регион из этого снимка для карточки и фильтров. Таблицы основного dashboard уже используют поле региона.

Существующие снимки с регионом отображают его сразу после обновления кода. При следующем штатном API-импорте регион обновляется во всех сохранённых экземплярах заявки, включая импортированные по письму. При этом сохраняются позиции, результаты поиска, статус, просмотр и реквизиты счёта. Для старых записей без снимка позиции восстанавливаются из сохранённого результата. Если источника региона нет ни в БД, ни в повторном импорте, отображается «не указан».

Отсутствующий ключ `region` в частичном ответе не стирает сохранённое значение; явно переданные `null` или пустое значение очищают его. Повторный импорт не запускает поиск поставщиков.

Проверки в `test_saved_dashboard.py`: сохранение исходного региона, отображение и экранирование HTML, отсутствие подмены городом, пустые и некорректные значения, обновление существующей обработанной заявки, восстановление старого снимка и обновление экземпляра из письма.

Изменение подготовлено локально; реальный импорт, поиск Sniper и публикация не запускались.
